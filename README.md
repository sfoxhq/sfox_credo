Credo checks used for Elixir projects at sFOX.

## Installation

Add `sfox_credo` to your dependencies in `mix.exs`:

```elixir
def deps do
  [
    {:sfox_credo, "~> 0.1"}
  ]
end
```

Documentation is found on [HexDocs][docs].
